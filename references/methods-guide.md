# 把方法用在眼前的事上

先问自己，这次究竟要作哪个决定。下面十个例子各从一个可以动手的地方开始。情境、做法和观察指标都是今天的应用示例。

1981 年《关于建国以来党的若干历史问题的决议》用“实事求是、群众路线、独立自主”概括贯穿毛泽东思想的立场、观点和方法。借到日常生活里，可以分别问：我的判断凭什么？受这件事影响的人怎么说？条件和责任在我这里，我有理由选哪条路？下面每节都列出可以回读的作品。[决议中的历史概括](https://www.12371.cn/2021/11/09/ARTI1636454249781129.shtml)

<a id="investigate"></a>

## 事情还没弄清，先查哪一段？

**方法**　实事求是、调查研究、分清事实和猜测

读书会接连两周没读完。有人说书太难，有人说下班后时间太碎。请一位读完的成员和一位中途停下的成员，各自还原最近一次阅读：从哪页开始，在哪里停下，当时发生了什么。两人若都卡在同一个例子，下一次就从那个例子带读；若一人读懂了却总被打断，先让他试一次较短的阅读时段，看看是否能接着往下读。

《反对本本主义》第七节谈到选熟悉情况的人参加调查，提前准备问题，让不同见闻相互核对。这个例子借的是提问办法，两个人的经历只能帮助决定下一步查什么。[《反对本本主义》第七节](https://www.12371.cn/2012/08/10/ARTI1344592797863461.shtml)

<a id="prioritize"></a>

## 几件事都急，今天先做什么？

**方法**　主要矛盾、抓重点、排优先级、弹钢琴

周五开放展览，海报、展签和场地确认都在催。请三位负责人各说清楚：今天哪项决定还没定，会让手里的哪一步做不了？如果印刷和布展都在等场地方确认尺寸，先定尺寸，同时给海报校对留出今天最后半小时。若印厂只在上午收件，而场地有可用的标准尺寸，就先确认这个尺寸能否送印，再排当天的工作。

《矛盾论》第四节讨论某种矛盾怎样影响其余矛盾。《党委会的工作方法》第五条以弹钢琴说明中心工作和其他工作怎样配合。这里分别借来判断谁牵动谁，以及哪些事还要按时照顾。[《矛盾论》第四节](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-193708.htm) · [《党委会的工作方法》第五条](https://news.12371.cn/2016/02/25/ARTI1456354051355105.shtml)

<a id="test-in-practice"></a>

## 两种办法争不出结果，如何试一次？

**方法**　实践检验、从结果修正认识、检验学习效果

你每天背单词，当晚全认识，隔两天却用不出来。挑两组熟悉程度相近的词，各花十分钟：一组照旧重读，一组合上书试着造句。两天后打乱顺序，看中文提示，写出词并造一个新句子。若重读的一组也能用出来，下轮换两组词再试；若两组都记得拼写，却都用错搭配，就把下一次练习改成比较例句。你要解决的问题可能已从记忆变成了用法。

《实践论》用考察团初到延安的例子区分所见所闻与进一步形成的认识，后文再谈把认识用于行动、根据结果修正它。这里借来检验的是你对自己“已经会用”的判断。[《实践论》](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-193707.htm)

<a id="listen-and-return"></a>

## 不同岗位都提了意见，怎样形成一个大家能用的办法？

**方法**　群众路线、听取不同意见、把办法交给使用者检验

图书馆拟缩短预约保留时间。前台看到座位空着，通勤学生反映公交到站不准，系统管理员只能看到超时记录。请三方分别拿一次实际预约说明经过，整理出一份试行办法，再让他们各自用自己的例子走一遍。例如到期前发提醒，让学生选择延时一次或放弃座位。试行后若空座少了，却有更多学生到了馆才知道座位已释放，就回访这些学生，调整提醒方式。

《关于领导方法的若干问题》第四条把收集分散意见、经过研究形成办法、交回实践检验连在一起。这个例子里，最后一步要听到实际用过办法的人怎么说。[《关于领导方法的若干问题》第四条](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19430601.htm)

<a id="pilot-and-expand"></a>

## 一个班试得好，什么条件下可以推广？

**方法**　从个别到一般、试点推广、比较适用条件

一个班用错题互评后，学生能更清楚地解释解题步骤。先问实施的老师，互评用了多少课时、学生遇到分歧时谁来解释。再找一个人数更多的班，只带去评分示例，观察同样一道新题能否讲清、老师用了多少时间。若大班里多数反馈只是打勾，先试每组共评一份并讲出理由。等第二个班也能在可用课时里做到，再决定推广到哪些班。

《关于领导方法的若干问题》第二条以整风学习为例，要求深入少数单位了解实行过程；第六条又谈到把所得经验拿到其他单位考验。这里借用的是比较条件、再作推广的顺序。[《关于领导方法的若干问题》第二、六条](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19430601.htm)

<a id="review-criticism"></a>

## 复盘会上有人批评你，怎样判断该改什么？

**方法**　批评和自我批评、复盘、接受反馈

活动结束后，新志愿者说签到指引让人跑了两趟。请他按当天收到的消息走一遍，你跟着核对通知和现场标牌。如果通知把取胸牌和签到写成了同一步，就当场认领这处改动，发新版给他试读。下次活动再听第一次来的人怎么走。若大家读懂了通知，仍被入口标牌带错方向，就把改动移到标牌，并把结果告诉提意见的人。

《为人民服务》第三段用李鼎铭提出的“精兵简政”说明判断一条意见要看其内容和实际益处。《论联合政府》谈自我批评时，用扫屋、洗脸比喻经常检点工作。这里既要回应具体批评，也要回来看改动有没有帮到当事人。[《为人民服务》第三段](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19440908.htm) · [《论联合政府》第三卷第1096页](https://ebook.theorychina.org.cn/ebook/upload/storage/files/2022/07/26/96241bf235bd68bad86fed6360e6a8bc32635/files/basic-html/page318.html)

<a id="independent-judgment"></a>

## 别人的经验很有说服力，我该照着做吗？

**方法**　独立自主、独立判断、借鉴经验

朋友每周日一次备好五天的饭，说这样省时间。你也想照做，可你经常临时加班，厨房只有一个小冰箱。先问他最省时间的是集中采购、一次洗切，还是把五顿都做好。你可以先为接下来的两顿共用一种配菜，记下准备和收拾的时间，以及临时变动后剩了什么。如果省下的时间主要来自少跑一趟菜场，就保留一次采购，把做饭时间留得灵活些。

《反对本本主义》第三节讨论怎样看待书里的说法和上级指示，提出要弄清它为什么符合实际。这里把同一个问题拿来问朋友的成功经验：在哪些条件下，它也能帮到我？[《反对本本主义》第三节](https://www.12371.cn/2012/08/10/ARTI1344592797863461.shtml)

<a id="handle-setbacks"></a>

## 做了一阵子还没起色，该坚持还是换办法？

**方法**　面对挫折、调整目标或方法、判断何时坚持

你练吉他一周，每次从头弹同一首曲子，总在同一处换和弦时停下。先只弹这一小节，把速度放慢到能听清每个音。若慢弹准确、提速就乱，保留这首曲子，逐步加速；若慢弹时同一个指法仍够不到，带着这一小节请老师看一次手形，再决定怎样练。若现在连完整练一遍的时间都难安排，也可以把这周目标缩到两个和弦之间的转换。

《实践论》后半篇讨论计划、方案在实行中受挫，原先的想法可能要随具体条件作部分乃至全部改变。这里把“想学会的曲子”和“每天从头弹一遍”分开考察，下一步取决于慢弹时实际听到了什么。[《实践论》后半篇](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-193707.htm)

<a id="who-benefits"></a>

## 一件事办得更快了，怎样知道它真的帮到了人？

**方法**　为人民服务、看实际受益、听到没有来的人

社区把周末修理活动改成线上预约。队伍短了，志愿者觉得流程顺了，却有位常来的老人连续两次没出现。先联系他，问他最近有没有东西想修、能不能约上。若他只是这两周用不着，就再找几位有需求的居民试填；若他有东西想修却卡在验证码，就让他试一次现场登记，同时记下志愿者多花了几分钟。下次用成功修好的件数、等候时间和进不了预约的人数一起来判断取舍。

《为人民服务》第三段借李鼎铭的意见说明，判断建议要问它能给人民带来什么益处。《关心群众生活，注意工作方法》举汀州开会的事，听众渐少，缺柴缺米的难处一直没人过问。借到今天，队伍变短可能因为办得快，也可能因为有人进不来；先问到那个人，才知道该改什么。[《为人民服务》](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19440908.htm) · [《关心群众生活，注意工作方法》](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19340127.htm)

<a id="work-through-disagreement"></a>

## 和搭档意见相反，还能怎样一起做事？

**方法**　团结合作、处理分歧、求同存异

两个人合编校刊，一人想多留时间核对引文，另一人担心错过印厂的截稿时间。先把双方都接受的目标说具体：周五拿到的刊物，读者可以按出处找到引文。一起看有没有没查到原文的段落，也问印厂最晚能替换哪一页。若只有一段失据，先就删去或改写这一段达成约定；若许多页都缺出处，就要重新谈篇幅或交期。讨论后各自复述一次约定，看看分歧究竟解决了哪一部分。

《关于正确处理人民内部矛盾的问题》第一部分在特定历史语境中讲“团结——批评——团结”，强调从愿意继续合作出发，通过讨论把分歧说清。应用到搭档之间，要保留对方继续提出异议的余地；如果双方对校刊用途本来就没有共识，应先谈用途，再谈印期。[1957 年发表稿，第一部分](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-19570227.htm)
